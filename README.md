# Systeme Point Zero

Cadre ontologique explorant les dynamiques qualitatives de l'existence, de la conscience et de l'auto-organisation. Un corpus philosophique de 168 fichiers, 15 millions de caracteres, construit sur 6 piliers interconnectes.

## Les 6 piliers

| Pilier | Domaine |
|--------|---------|
| **Point Zero** | Fondement ontologique — unimulticite, intrajection, inepuisabilite |
| **Ether Fluide** | Physique qualitative — dualite Vertical/Horizontal, torsions vectorielles |
| **Geometrie Qualitative** | Mathematique du systeme — Matrice Reflective, N-spin, topologie chiffonnee |
| **Conscience** | Meta-organe sensoriel — conscience nodale, ecologie de l'ame |
| **Organisation Systemique Spontanee** | Auto-organisation — Intelligence Idiopathique, champs de coherence |
| **INTemple** | OS philosophique operationnel — incarnation pratique du corpus |

## Stack

Python (stdlib), HTML/CSS/JS standalone, JSON comme format pivot. Pas de framework, pas de build. Les interfaces qui utilisent l'IA passent par l'API Anthropic ou Ollama.
